# TayStack Lab

Welcome to the TayStack Lab.

This repository contains the scripts, configurations and resources used throughout the TayStack YouTube series.

The aim of TayStack is to build a Microsoft lab from scratch and use it to explore real-world endpoint management, troubleshooting and automation.

## What We're Building

The TayStack Lab will cover technologies including:

- Microsoft Intune
- Microsoft Entra ID
- Microsoft 365
- Windows 11
- PowerShell
- WinGet
- Application deployment
- Endpoint management
- Automation

Everything is built and tested in the lab as the series progresses.

## Episodes

### Episode 1 - Building the Microsoft 365 Tenant

Created the TayStack Microsoft 365 environment and connected the TayStack domain.

### Episode 2 - Building Our First Intune Managed Device

Enabled Hyper-V, created our first Windows 11 virtual machine, joined it to Microsoft Entra ID and enrolled it into Microsoft Intune.

During the build we also encountered an MDM enrollment issue and worked through diagnosing and resolving it.

Scripts and commands used during troubleshooting can be found in:

## Using the Scripts

The scripts in this repository are provided as examples from the TayStack lab.

Before running any script:

1. Read and understand what it does.
2. Review it for your own environment.
3. Test it in a lab.
4. Never assume a script is suitable for production without testing.

Some scripts may make changes to devices, applications, registry settings or Microsoft cloud services.

Use them at your own risk.
